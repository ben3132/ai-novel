# 第三章 断指引

苏挽的铜铃在暗处叮当作响。林晓推开窗，月色下那道白衣身影已立在屋顶。

"沉渊阁断指明路，从不虚发。"苏挽蹲下身，"那焦尸是沉渊阁阁主的亲传弟子，司徒烈。他偷了阁中'断指引'叛逃，却被自己的同门灭口——下手的人，用的是你们听风阁的'无影手'。"

"不可能。"林晓斩钉截铁，"无影手全阁只有两人会，师父和我。师父……七年前已经死了。"

"死没死，要看这封信。"苏挽从袖中抽出一封蜡封密信，封口处盖的，正是听风阁阁主的私印。

林晓接过信，指尖发凉。信上只有八个字：铁令出，天下乱；汝守，吾去。

"你师父没死。"苏挽望着他，"十二年前铁令失窃，七年前青云山假死，三日前沉渊阁内讧——有人在用这两枚铁令，下一盘很大的棋。"

远处传来马蹄声。苏挽神色一变："是沉渊阁的追兵。跟我走。"

林晓最后看了一眼青石巷方向，收好信，纵身跃上屋顶。

黑暗中，他握紧腰间那枚铁令，第一次感到彻骨的寒意——师父留给他的人生，从头到尾，都是一局早已布好的棋。
