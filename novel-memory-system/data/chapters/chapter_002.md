# 第二章 焦尸

翌日，仵作在衙门口当众验尸，围观的百姓挤了三层。林晓混在人群里，目光落在焦尸右手的断指上——中指齐根而断，这是"沉渊阁"处决叛徒的规矩。

"听风阁的探子死在沉渊阁的刀下，这仇结得蹊跷。"一道清冷女声从身侧传来。林晓转头，看见一袭白衣的女子，腰间挂着一枚铜铃，正是江湖人称"铃医"的苏挽。

"姑娘认错了人。"林晓转身欲走。

"七年前青云山一战，是你背走了重伤的听风阁主。"苏挽不紧不慢，"你左手虎口的旧疤，藏不住。"

林晓脚步一顿。这个女子知道得太多了。

当夜，林晓潜回听风阁分舵，翻查卷宗，发现三日前总舵传来密令：追查一枚失落十二年的铁令。而昨晚粮仓那具焦尸，腰间铁令恰与他身上那枚是一对。

师父留下的信物，竟与十二年前失窃的铁令同源。师父他，到底卷进了什么？

窗外响起三声梆子。林晓吹熄油灯，黑暗中有人轻笑："你终于查到这一步了。"
