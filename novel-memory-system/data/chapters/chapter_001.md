# 第一章 风起青石巷

暮色压城，青石巷尽头的茶摊刚点上油灯。林晓把斗笠压低，在摊边坐下，指尖划过碗沿，盯着巷口那道鬼鬼祟祟的影子已经半个时辰。

"客官，天要黑了，这条巷子不太平。"茶博士压低嗓音。

林晓没答话，拇指在碗底轻轻一叩——这是七年前师父教他的暗号。师父说过，青石巷的茶博士，是"听风阁"埋了十一年的钉子。

巷口那影子忽然转身，快步朝东走去。林晓放下茶钱起身，身形一晃便没入檐影。

东城墙根的暗哨今夜被换成了生面孔，这不合规矩。听风阁的线，不该有他不知道的变化。

是夜三更，城东粮仓起火，火光映红半座城。林晓立在仓顶残梁上，看着火场中那具焦尸腰间半枚铁令——与他身上那一枚，严丝合缝。
